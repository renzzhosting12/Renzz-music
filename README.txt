RENZZ MUSIC v12

Cara menjalankan:
1. Ekstrak ZIP ini.
2. Buka index.html menggunakan browser modern (Chrome/Edge/Firefox).
3. Untuk pencarian lagu online, perangkat harus terhubung ke internet.
4. Untuk memutar koleksi pribadi, gunakan tombol Tambah koleksi / Pilih file audio.

Catatan:
- Hasil pencarian online berasal dari katalog Audius.
- Tombol YouTube, Spotify, SoundCloud, Deezer, dan Google membuka halaman pencarian resmi masing-masing.
- Website ini tidak menyertakan API key atau backend server.
- File audio lokal dipilih dari perangkat pengguna dan tidak diunggah.
