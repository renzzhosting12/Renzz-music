# Renzz Music

Static music-player website, ready to deploy on Vercel.

## Deploy with GitHub + Vercel
1. Extract this ZIP.
2. Create a new GitHub repository and upload `index.html`, `vercel.json`, and this README to the repository root.
3. In Vercel, choose **Add New → Project** and import that GitHub repository.
4. Keep the Framework Preset as **Other**.
5. Leave Build Command and Output Directory empty (or use `.` as the output directory).
6. Click **Deploy**.

## Music playback
Use **Tambah lagu / Pilih file audio** to load audio files from your device. The player plays the complete duration of the selected local audio file. This starter version does not include a hosted music catalog, user accounts, cloud uploads, or streaming licensed commercial music. To offer shared online music libraries, add authorized audio files and a backend/storage service with appropriate rights.
